## Acceptance coverage

- T01: Core `TelemetryRequestTests` covers public and generated sync/Task/ValueTask hits, misses, L2 hits,
  flight joiners, refresh, throttled stale fallback, bypasses, errors and bulk calls. Only actual origins record
  load durations. `CoreTelemetryTests` proves container/factory isolation and existing-factory reuse.
  `CoreInstrumentationTests` verifies the actual SDK exporter and fractional-second precision with fake time.
- T02: Core/backend canaries and actual SDK-exported spans/metric points cover default privacy, hashed/raw
  key opt-ins, application tag opt-ins and omission of exception text/HTTP attributes. Standard app-owned
  activity context and baggage remain intact; no cache identity baggage is added. Transport diagnostic logs
  and health failures export exception types, never backend exception messages.
- T03: SDK subscription before/after Core and repeated subscriptions create no wrappers or duplicate events.
  Scoped/transient/type/factory/instance/async disposal ownership, keyed registrations, one-time key generation,
  nullable lookups and bulk L2 reads retain regression coverage. Generated sync/Task/ValueTask hit probes add
  zero telemetry allocations with listeners off/on, including concurrent measurements. The probe makes engine
  maintenance inline to exclude unrelated thread-pool work-item allocations. .NET 9/10 baseline is zero;
  .NET 8 retains its existing string-key allocations and subscribing adds none.
- T04: storage/publication stages and gauges are independent. Healthy L2 with unknown/connecting/disconnected
  backplane is degraded using the selected failureStatus. NoOp/custom capability does not invent method stats.
  Redis health waits for initial/reconnect subscription acknowledgement and recovery clear; an older recovery
  cannot overwrite a newer failure. Real SQL tests cover established polling, failed delivery and recovery.
- T05: local method counts and configured weights are independent of HTTP resident counts/bytes and bounded
  distributed observations. Stats do not serialize results or invoke hostile payload getters. Actual HTTP
  store integration is intentionally exercised in the following HTTP implementation step.

Deleted tests targeted explicitly removed provider/wrapper, baggage, estimated-memory and sampling APIs. Their
applicable privacy, lifecycle, nullable lookup, forwarding and allocation behaviors are exercised against Core and
the real SDK above; there are no obsolete compatibility shims. Generated ABI tests remain unchanged.
